# 🎹 WEBSYNTH

Простой веб-синтезатор, построенный на React и Tone.js, с визуальным интерфейсом для создания и настройки звуков.

## Особенности

- **Несколько форм волн**: синус, квадрат, пила, треугольник, импульс и расширенные "жирные" версии
- **Контроль огибающей**: ADSR (Attack, Decay, Sustain, Release)
- **Эффекты**: дисторшн, хорус, реверберация
- **Управление пресетами**: локальное сохранение, загрузка из файлов, синхронизация с сервером
- **Управление с клавиатуры**: играйте ноты с клавиатуры компьютера
- **Визуальная клавиатура**: интерактивная клавиатура с подсветкой активных нот
- **Чистый интерфейс**: минималистичный дизайн с фокусом на удобство использования

## Быстрый старт

### Предварительные требования

- Node.js 16+
- npm или yarn
- Современный браузер с поддержкой Web Audio API

### Установка

```bash
# Клонирование репозитория
git clone [repository-url]
cd cd react-web-synth

# Установка зависимостей
npm install
# или
yarn install

# Запуск в режиме разработки
npm run dev
# или
yarn dev
```

### Запуск с бэкендом (опционально)

```bash
# Настройка переменных окружения
cp .env.example .env.local

# Запуск Django сервера (требуется Python 3.8+)
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

# Запуск фронтенда
cd ../frontend
npm run dev
```

## Формы волн

Синтезатор поддерживает следующие формы волн:

### Основные

- **Sine (Синус)** - чистый, мягкий звук
- **Square (Квадрат)** - полый, "гудящий" звук
- **Sawtooth (Пила)** - яркий, богатый гармониками
- **Triangle (Треугольник)** - мягкий, похож на синус с гармониками

### Расширенные

- **Pulse (Импульс)** - прямоугольная волна с настраиваемой шириной импульса
- **Fat Sawtooth** - "жирная" пилообразная волна с расстройкой
- **Fat Triangle** - "жирная" треугольная волна с расстройкой

## Элементы управления

### Основные настройки

1. **Waveform** - выбор формы волны осциллятора
2. **Volume** - общая громкость (-24dB до 0dB)
3. **Envelope (ADSR)**:
   - **Attack** - время нарастания (0-5 секунд)
   - **Decay** - время спада (0-2 секунды)
   - **Sustain** - уровень поддержки (0-1)
   - **Release** - время затухания (0-5 секунд)

### Эффекты

- **Distortion** - добавляет гармоники и насыщение
- **Chorus** - создает эффект хора/ансамбля
- **Reverb** - добавляет пространственное ощущение

### Управление пресетами

- **Сохранить в файл** - экспорт настроек как JSON
- **Загрузить из файла** - импорт пресетов
- **Опубликовать** - загрузка пресета на сервер
- **Выбор пресета** - локальные и серверные пресеты
- **Сброс** - возврат к настройкам по умолчанию

## Управление с клавиатуры

Синтезатор поддерживает управление с компьютерной клавиатуры:

```bash
Белые клавиши:    A S D F G H J
Черные клавиши:   W E T Y U
Октава вверх:     Z
Октава вниз:      X
```

## Технологии

- **React 18** - библиотека для построения пользовательских интерфейсов
- **Tone.js** - веб-фреймворк для создания интерактивной музыки в браузере
- **Styled Components** - CSS-in-JS для стилизации
- **React Icons** - коллекция иконок
- **Web Audio API** - низкоуровневый API для работы со звуком

## Производительность

Синтезатор оптимизирован для работы в современных браузерах:

- **Полифония**: до 8 одновременных нот
- **Задержка**: низкая задержка ввода (< 20 мс в современных браузерах)
- **Память**: эффективное использование Web Audio API

### Создание собственных пресетов

```javascript
// Пример ручного создания пресета в виде json файла
const customPreset = {
    oscillator: 'fatsawtooth',
    volume: -12,
    envelope: {
        attack: 0.05,
        decay: 0.2,
        sustain: 0.7,
        release: 1.2,
    },
    effects: {
        distortion: { active: false, distortion: 0.3 },
        chorus: { active: true, frequency: 2.0 },
        reverb: { active: true, decay: 2.0 },
        limiter: { active: true },
    },
};
```

### Логирование

Синтезатор использует консольное логирование для отладки:

- `console.log` - информация об инициализации
- `console.warn` - предупреждения
- `console.error` - критические ошибки

**Примечание**: Этот синтезатор работает полностью в браузере и не требует установки дополнительного программного обеспечения. Все звуки генерируются в реальном времени с помощью Web Audio API.
